# Modelo Céu — LojaZapi

URL sugerida: `https://lojazapi.flexiweb.com.br/modelos/ceu/`

Este modelo já contém catálogo demonstrativo com produtos, kits e serviços, carrinho local e envio do pedido pelo WhatsApp.

- Edite `products.js` para trocar itens, preços, descrições e imagens.
- Edite `config.js` para trocar o WhatsApp e o nome da loja de demonstração.
